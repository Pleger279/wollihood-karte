Einmal verbinden

Damit diese Seite die Kriterien im Repo speichern kann, braucht sie einen GitHub-Schlüssel. Er bleibt nur in diesem Browser gespeichert.

  1. Öffne neuen Schlüssel erstellen.
  2. Name «Wollihood Karte», Ablauf z. B. 1 Jahr. Bei «Repository access» nur wollihood wählen.
  3. Unter «Permissions → Contents» Read and write wählen, erstellen, Schlüssel kopieren.
